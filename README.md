付箋などの実物体によって投影映像内の物理挙動を変化させるインタラクションシステム
# PPP - Poppy Projection Playground -

## 概要

PPPは，付箋などの実物体を用いて，投影映像内の物理挙動を変化させるインタラクションシステムです。

本システムでは，Unity上で動作する物理シミュレーション映像をプロジェクターやモニターに表示し，その表示面をカメラで撮影します。表示面に貼られた付箋などの実物体を検出し，その位置や角度をUnity内の仮想オブジェクトとして反映することで，映像内のボールの動きや衝突挙動を変化させます。

体験者は，画面に直接触れるのではなく，現実空間に物体を貼る・動かす・剥がすという行為によって，仮想空間内の物理シミュレーションに介入します。これにより，現実の物体操作と仮想世界の挙動がつながっているような，直感的なインタラクションを実現します。

## コンセプト

通常，映像内の物理シミュレーションは，マウスやキーボード，ゲームコントローラーなどを通じて操作されます。一方でPPPでは，付箋のような身近な実物体を操作手段として用います。

たとえば，壁に投影された映像内でボールが落下しているとき，体験者が表示面に付箋を貼ると，その位置に仮想的な障害物が生成されます。ボールはその障害物に衝突し，跳ね返ったり，進行方向を変えたりします。

このように，現実空間に配置した物体が仮想空間内の物理挙動に影響を与えることで，体験者は「自分の手で映像の中に介入している」感覚を得ることができます。

## 主な特徴

* 付箋などの身近な実物体を用いた直感的な操作
* カメラによる実物体の位置・角度検出
* 検出結果をUnity内の物理オブジェクトとして反映
* 映像内のボールや物体の挙動をリアルタイムに変化
* 子どもから大人まで理解しやすい物理パズル的な体験
* プロジェクターだけでなく，モニター表示でも動作可能

## システム構成

PPPは，主に以下の要素で構成されています。

1. **Unityによる物理シミュレーション**

   * ボールの落下や衝突などの物理挙動をUnity上で再現します。
   * 検出された実物体に対応する仮想オブジェクトを生成し，物理演算に反映します。

2. **カメラによる表示面の撮影**

   * プロジェクターやモニターに表示された画面全体をカメラで撮影します。
   * 撮影画像から，表示領域と実物体の位置を取得します。

3. **キャリブレーション**

   * カメラ画像内の表示領域を，Unityの画面座標に対応付けます。
   * これにより，現実空間上の付箋の位置を，Unity内の座標へ変換します。

4. **付箋検出**

   * 色や形状をもとに，画面上に貼られた付箋などの矩形物体を検出します。
   * 検出した物体の位置・大きさ・角度を取得します。

5. **Unityと検出処理の連携**

   * 検出結果をUnityに送信し，対応する仮想オブジェクトを生成・更新します。
   * 実物体を動かすと，仮想オブジェクトの位置や角度も変化します。

## 体験内容

体験者は，投影映像内を落下するボールを，付箋を用いて誘導します。

付箋を貼ると，映像内にその付箋と対応する障害物が生成されます。体験者は，付箋の位置や角度を調整しながら，ボールの跳ね返り方を変化させ，ゴールへ導くことを目指します。

この体験では，画面内のオブジェクトを直接操作するのではなく，現実空間に置いた物体によって仮想世界の挙動を変化させる点が特徴です。

## 使用技術

* Unity
* 物理シミュレーション
* カメラ画像処理
* 付箋・矩形物体の検出
* 表示領域のキャリブレーション
* Unityと外部処理の連携

## 想定される利用場面

PPPは，展示作品や体験型コンテンツとしての利用を想定しています。

特別なコントローラーを必要とせず，付箋を貼るという日常的な行為で操作できるため，子どもから大人まで直感的に体験できます。また，物理シミュレーションの結果がリアルタイムに変化するため，遊びながら試行錯誤できるインタラクティブな作品として活用できます。

## 今後の展望

今後は，単に障害物を配置するだけでなく，付箋の色や種類によって異なる効果を持たせることを検討しています。

たとえば，通常の壁として機能する付箋，強く跳ね返す付箋，ボールを引き寄せる付箋，特定の方向へ加速させる付箋などを用意することで，より多様な物理パズル体験に発展させることができます。

また，複数人で同時に付箋を配置し，協力しながらボールを誘導するような展示形式への展開も考えられます。
